## FEA refinement

Default geometry, 1000 N, E=3000 MPa, ν=0.35, roller grip, uniform traction:

| Radial / angular divisions | Elements | Maximum displacement (mm) | Peak element Δσ (MPa) |
|---|---:|---:|---:|
| 8 / 32 | 576 | 0.176697 | 14.0180 |
| 16 / 64 | 2176 | 0.177377 | 15.4453 |
| 32 / 128 | 8448 | 0.177569 | 15.9784 |

The final displacement change is about 0.11%; peak stress changes about 3.45%. Local peak stress is still mesh dependent. Force reactions balance the applied 1000 N within 10⁻⁷ N in these checks. A constant-strain displacement patch independently tests the element strain operator.

## Held-out synthetic reconstruction

Exact FEA orientation prior, assumed coefficient 3×10⁻¹² Pa⁻¹, 5 mm thickness, crossed analyzer, wavelengths 630/525/450 nm, seeded independent Gaussian intensity noise σ=0.001, search range 0–30 MPa:

| Load | Valid material pixels | Valid fraction | RMSE on valid pixels (MPa) | Empirical approximate 95% interval coverage |
|---|---:|---:|---:|---:|
| 600 N | 537 / 2148 | 25.0% | 1.07465 | 93.67% |
| 1400 N | 733 / 2148 | 34.12% | 1.40528 | 95.63% |

Most of the field is weakly sensitive or unresolved under crossed illumination; it is not reported as successfully reconstructed. The intervals are conditional local approximations and omit calibration/model uncertainty. This is a numerical model-consistency study, not experimental validation. Full machine-readable results are in `outputs/validation.json`, regenerated by `polaris validate --held-out`.
